# Proposal

## Why
O banner de altura fixa recorta a tartaruga ao preencher a largura. O usuário deseja a arte inteira ocupando todo o espaço.

## What Changes
Altura proporcional à largura usando a proporção 16:9 original do vídeo.

## Capabilities
Ajuste visual do contrato existente, sem novas capacidades.

## Impact
Somente CSS compartilhado; sem dados, autorização ou transporte alterados.
