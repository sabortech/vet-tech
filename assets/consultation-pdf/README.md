# Elementos do relatório VetTech

`mascote-v.png` e `mascote-canto.png` são os gráficos individuais extraídos, com transparência, do PDF oficial fornecido pelo usuário em `docs/templates/vettech-prontuario-referencia.pdf`. Não são imagens de página nem fundos de relatório. O layout, a marca d'água, os textos e as tabelas são gerados por ReportLab.

A referência original permanece em `docs/`. Estes dois assets locais são a allowlist do renderizador; dados clínicos nunca definem caminhos ou URLs de imagem.
